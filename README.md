# Дворовая лига — Жеребьёвка

Отдельное статическое веб-приложение для жеребьёвки 16 футбольных команд на две группы по 8 с учётом рейтинга.

## Возможности

- Ручной ввод 16 команд в порядке рейтинга (места 1–16).
- Автоматическое разбиение на 4 корзины по 4 команды.
- Поэтапная жеребьёвка по одной команде с анимацией.
- Ровно по 2 команды из каждой корзины в каждой группе.
- Криптографически надёжный источник случайных чисел (`crypto.getRandomValues`), без округлительного смещения при выборе.
- Полноэкранный режим, пробел для следующего шага.
- Восстановление состояния после перезагрузки (localStorage).
- Экспорт итоговой таблицы в PNG.
- Адаптивный интерфейс без backend и зависимостей.

## Запуск локально

Откройте `index.html` в браузере или запустите статический сервер в корне проекта, например `python -m http.server 8080`, затем перейдите на `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий `dvoro-liga-draw`.
2. Загрузите `index.html`, `styles.css`, `app.js` в корень ветки `main` (и этот README).
3. Перейдите в **Settings → Pages → Build and deployment** и выберите **Deploy from a branch**, затем **main** и **/(root)**, нажмите **Save**.
4. Сайт появится по адресу `https://USERNAME.github.io/dvoro-liga-draw/` (замените `USERNAME` своим логином).

## Регламент

Рейтинг №1–4 — корзина 1, №5–8 — корзина 2, №9–12 — корзина 3, №13–16 — корзина 4. Жеребьёвка проходит последовательно по корзинам. На каждом шаге случайно выбирается одна ещё не выбранная команда текущей корзины и одна из групп, где ещё есть место для команды из этой корзины. Две команды из корзины попадают в A, две — в B.

Приложение предназначено для одного организатора, работающего в одном браузере. Публичный адрес не синхронизирует жеребьёвку между зрителями: для распространения результатов используйте экспорт PNG.

Шрифты подгружаются из Google Fonts при наличии доступа к сети; при отсутствии связи используются локальные резервные шрифты.
